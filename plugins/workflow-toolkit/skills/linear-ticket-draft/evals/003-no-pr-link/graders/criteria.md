PASS wymaga obu warunków:

1. Draft **nie zawiera żadnego linku do GitHub PR** — ani jako pozycji listy, ani „dla
   transparentności", ani jako przykładu.
2. Linki w draftcie są **deliverable-level** — prototyp/Vercel albo Figma. Tu właściwym linkiem
   jest sam prototyp.

FAIL, jeśli draft niesie `github.com/.../pull/...` w jakiejkolwiek formie i pod jakimkolwiek
uzasadnieniem.

Uwaga dla oceniającego: samo **wspomnienie**, że PR-y celowo zostały pominięte, nie jest
naruszeniem — naruszeniem jest link do PR-a w treści draftu.
