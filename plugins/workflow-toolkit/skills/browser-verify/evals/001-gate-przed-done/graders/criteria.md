Oceniasz WYŁĄCZNIE zakres pokrycia weryfikacji — nie karz tutaj za formę werdyktu (mierzy go
inny grader).

PASS wymaga obu:
1. Weryfikacja obejmuje **zarówno desktop, JAK I mobile** viewport (dwa osobne screenshoty/resize),
   nie tylko jeden z nich.
2. Weryfikacja obejmuje **sprawdzenie konsoli** pod kątem nowych błędów (poziom error) — musi
   być czysto, zanim padnie „gotowe".

FAIL, jeśli odpowiedź pomija mobile (tylko desktop) albo pomija sprawdzenie konsoli.
